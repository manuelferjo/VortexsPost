Vortexs Post

by Vortexs · v1.0

Sube un vídeo a YouTube, TikTok e Instagram de una vez: con el mismo título o uno distinto en cada red, ahora o programado, y con ajustes guardados como «mañana a las 15:00».

Cómo funciona

Tu vídeo→Vortexs Post→YouTubeTikTokInstagram

Usa las APIs oficiales de cada red (nada de bots ni de contraseñas): tú conectas tus cuentas una vez y el programa guarda los permisos cifrados en tu PC.

RedCómo se programa
YouTubeEl vídeo se sube en cuanto lo programas y YouTube lo publica solo a la hora elegida, aunque apagues el PC.
TikTokTikTok no deja programar desde fuera: Vortexs Post lo sube y lo publica a la hora. El PC tiene que estar encendido con el programa abierto (vale en la bandeja).
InstagramIgual que TikTok: el reel se sube 10 minutos antes y se publica a la hora. PC encendido y programa abierto.

Si el PC estaba apagado a la hora, lo pendiente se publica en cuanto abras el programa (y en la cola se apunta el retraso). Para que no pase: Ajustes → Abrir con Windows y Que el PC no se suspenda.

Antes de nada: las auditorías IMPORTANTE

YouTube y TikTok tratan igual a todas las apps nuevas, también a la tuya aunque sea solo para ti:

  • YouTube: lo que sube un proyecto de Google sin auditar se queda en privado. Hay que rellenar una vez el formulario de auditoría de «YouTube API Services».
  • TikTok: una app sin auditar solo publica en «Solo yo» y con la cuenta en privado. Hay que pedir la revisión de la Content Posting API.
  • Instagram: funciona ya con tu propia cuenta (la app en modo desarrollo vale para las cuentas que tengan un rol en ella).

Mientras esperas, puedes probarlo todo: los vídeos llegan, pero privados. Las auditorías son gratis y tardan de unos días a unas semanas.

1Crear el programa

  1. Descomprime la carpeta y abre build.bat: crea VortexsPost.exe con el compilador que ya trae Windows (como Vortexs Live).
  2. O súbelo a un repositorio de GitHub: la pestaña Actions lo compila sola y deja el ZIP para descargar.

Requisitos: Windows 10 u 11. Tus cuentas y la cola se guardan en VortexsPost.json junto al .exe (los tokens, cifrados: solo valen en tu usuario de Windows).

2Conectar YouTube

  1. Puedes usar el mismo proyecto de Google que Vortexs Live: en la pestaña Cuentas pega el mismo Client ID y Client secret (cliente de tipo «TVs y dispositivos de entrada limitada»).
  2. Si empiezas de cero: Google Cloud → crea un proyecto → APIs y servicios → Biblioteca → activa YouTube Data API v3 → Pantalla de consentimiento (externa, añádete como usuario de prueba) → Credenciales → Crear ID de cliente OAuth → tipo TVs y dispositivos de entrada limitada.
  3. Pulsa Conectar: se abre google.com/device, escribe el código y elige tu canal.
  4. Para publicar en público: pide la auditoría en el formulario YouTube API Services – Audit and Quota Extension (explica que es una herramienta para subir tus propios vídeos).

3Conectar TikTok

  1. TikTok for Developers → Manage apps → Connect an app.
  2. Añade el producto Login Kit: en la plataforma Desktop, como Redirect URI pon http://127.0.0.1:*/callback/
  3. Añade Content Posting API y activa Direct Post. Permisos: user.info.basic y video.publish.
  4. En Cuentas pega el Client key y el Client secret y pulsa Conectar: se abre TikTok en el navegador, autoriza y el programa lo recibe solo.
  5. Para probar antes de la auditoría: pon tu cuenta en privado y publica en «Solo yo». Después pide la revisión de la app (Submit for review) para publicar en público.

TikTok exige que elijas cada vez quién puede verlo (no hay opción marcada por defecto) y enseña tu nombre y el aviso de la «Music Usage Confirmation». Vortexs Post ya lo hace así para que la revisión no ponga pegas. Puedes dejar la privacidad guardada en un ajuste.

4Conectar Instagram

  1. Tu cuenta de Instagram tiene que ser profesional (Creador o Empresa).
  2. Meta for Developers → Crear app → caso de uso de Instagram (API de Instagram con inicio de sesión de Instagram).
  3. En Roles, añade tu cuenta como tester de Instagram y acepta la invitación desde Instagram (Configuración → Apps y sitios web → Invitaciones de tester).
  4. En la configuración de la API de Instagram, junto a tu cuenta pulsa Generar token (con los permisos instagram_business_basic y instagram_business_content_publish).
  5. Pega el token (empieza por IGAA) en Cuentas y pulsa Conectar. Dura 60 días y el programa lo renueva solo cada semana mientras lo abras.

También vale un token de Facebook (empieza por EAA) si tu Instagram está unido a una página: el programa busca la página y usa su token.

5Publicar

  1. Vídeo: arrástralo a la ventana o pulsa «Elegir vídeo». Para las tres redes, mejor vertical 9:16 en MP4.
  2. Dónde: marca YouTube, TikTok y/o Instagram.
  3. Todas: título, descripción, hashtags y cuándo. YouTube usa el título como título y pone la descripción y los hashtags debajo; TikTok e Instagram juntan todo en el texto.
  4. Títulos distintos: elige la red arriba a la derecha y activa Texto propio. Con Hora propia, esa red sale a otra hora (por ejemplo TikTok a las 15:00 e Instagram a las 18:00).
  5. Pulsa Programar (o Publicar ahora) y sigue el progreso en la pestaña Cola, donde puedes cancelar, reintentar o abrir lo publicado.

6Ajustes guardados

Deja la pestaña Publicar como la usas siempre (por ejemplo: las tres redes, Mañana a las 15:00, TikTok para «Todos», tus hashtags fijos) y pulsa Guardar como ajuste. Luego lo eliges de la lista con un clic.

En la pestaña Ajustes marca uno con ★ Al abrir para que se aplique solo cada vez que abras el programa (y después de cada publicación). Se guardan las redes, la hora de cada una, los hashtags y las opciones; el título y la descripción no, porque cambian con cada vídeo.
